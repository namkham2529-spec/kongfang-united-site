สมัคร LINE Official Account

บัญชีธุรกิจของ LINE ใช้ฟรี แชทตอบลูกค้า 1:1 ได้ไม่จำกัด บรอดแคสต์ได้ 500 ข้อความ/เดือน

  1. เข้า LINE Official Account Manager

    เปิด manager.line.biz ล็อกอินด้วยบัญชี LINE ของร้าน (แนะนำใช้เบอร์/อีเมลกลางของร้าน ไม่ใช่ไลน์ส่วนตัว)

  2. สร้างบัญชีใหม่

    กด “สร้างบัญชี” → ชื่อบัญชี: กองฟาง ยูไนเต็ด · ชุดแข่ง · หมวดหมู่: สินค้า/ค้าปลีก — เสื้อผ้า · ประเทศ: ไทย

    ชื่อเปลี่ยนภายหลังได้ แต่จะเปลี่ยนได้จำกัดรอบ ตั้งให้ตรงตั้งแต่แรก

  3. ยืนยันอีเมล แล้วเข้าหน้าจัดการบัญชี

    จำ LINE ID (@ตามด้วยตัวอักษร) และลิงก์เพิ่มเพื่อน ไว้ใช้ในส่วนถัดไป

  4. เพิ่มแอดมิน (ถ้ามีทีมงาน)

    ตั้งค่า → จัดการสมาชิก → เชิญด้วยอีเมล/ไลน์ กำหนดสิทธิ์เป็น “ผู้ดูแล” หรือ “ผู้ตอบแชท”

  5. เปิดโหมดแชท

    ตั้งค่าตอบกลับ → เปิด “แชท” (เพื่อให้แอดมินพิมพ์คุยได้) และเปิด “ตอบกลับอัตโนมัติ” ควบคู่กัน — ส่วน D จะมาตั้งคีย์เวิร์ดตรงนี้

ℹ️ชื่อเมนูในหน้า LINE OA อาจต่างจากคู่มือเล็กน้อยตามเวอร์ชัน แต่ลำดับงานเหมือนกัน · การทำบัญชี “ยืนยันตัวตน” (มีโล่) ไม่บังคับ มีค่าธรรมเนียมแยก ทำภายหลังได้
